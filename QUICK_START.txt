SMART HOSPITAL BED ALLOCATOR - QUICK START

1. Install Python 3.11 or newer from https://www.python.org/downloads/.
2. Extract this ZIP into a normal folder (do not run from inside the ZIP).
3. Double-click setup_and_run.bat.
4. Wait for dependencies to install. Internet is required for the first setup.
5. Open http://127.0.0.1:5000 in your browser.
